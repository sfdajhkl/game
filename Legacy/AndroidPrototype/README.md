# 여명의 서 · Dawn Chronicle

안드로이드용 오프라인 텍스트 로그라이크의 첫 플레이 버전입니다. **16세에 시작해 선택으로 시간을 보내고, 동료와 턴제 전투를 치르며, 사망하거나 수명이 다하면 한 생을 마칩니다.**

## 실행 파일

- `dist/dawn-chronicle-v0.1.0-debug.apk`: 직접 설치하는 테스트용 APK. Android 8.0(API 26) 이상, 세로 화면.
- 앱 이름 **여명의 서**, 패키지 `com.dawnchronicle.game`, 버전 `0.1.0`.
- 인터넷 권한, 계정, 광고, 결제, 서버가 없습니다. 코드·배경·한글 글꼴을 APK에 포함했습니다.
- 개발용 서명입니다. 스토어 배포용 서명과 실제 기기 검증은 별도로 진행해야 합니다.

## 구현된 게임

- **23개 사건**: 출발, 첫 전투, 장비 선택, 아이 구조와 재회, 동료 영입, 도적, 유적 해독, 파수꾼, 용, 상단, 수련, 대장간, 계절, 묘지, 다리, 학자, 귀향, 후진 양성, 노년, 보급.
- 각 선택은 **최소 1주**, 길게는 5년이 흐릅니다. 한 해는 52주입니다. 여행, 수련, 정착에 서로 다른 시간을 부여했습니다.
- 고정 직업이 없습니다. **7종 무기**를 장착하면 해당 기술이 바뀌고, 별도로 배운 기술은 유지됩니다. 경험으로 성장 단계·체력·공격력이 오릅니다. 무기 숙련은 8회 사용마다 피해 +1, 최대 +3입니다.
- **동료 3명**, 주인공 포함 **최대 4명**. 미라(활), 엘리안(치유·마법), 보린(근접). 영입과 일부 사건이 과거 선택을 기억합니다.
- 속도순 턴제. 모든 아군의 행동을 직접 선택합니다. 1열이 전열이며 무기·기술별 사용 열과 대상 열이 다릅니다. 아군·적이 쓰러지면 빈자리가 당겨집니다.
- 출혈, 기절, 방어, 기력, 치유, 긴장, 자리 교대, 회복약, 퇴각을 구현했습니다. 긴장 100에서 한 차례를 잃고 65로 내려갑니다. 의지는 적에게서 받는 긴장 피해를 줄입니다.
- 주인공의 체력이 0이면 종료. 동료의 죽음도 이번 생에는 영구적입니다. 퇴각은 항상 성공하지만 골드 20%와 긴장 +12를 대가로 치릅니다.
- 사건 플래그로 구조한 아이와 재회, 유적 단서, 파수꾼, 용 등 후속 사건이 열립니다. 최종 적을 물리쳐도 삶은 계속됩니다. 마지막에는 삶의 업적에 맞는 별칭과 연대기를 남깁니다.
- **유대**는 함께 쉰 계절을 기록하는 서사 수치이며 현재 전투 보너스는 없습니다.
- 새 생은 장비·능력치가 초기화됩니다. 최근 12개 생의 요약만 따로 보관하며 영구 능력치 강화는 넣지 않았습니다.

## 수명 규칙

16~39세에는 노화 사망이 없습니다. 40세부터 매주 아래 확률을 판정합니다.

```
연간 위험 = min(0.98, 0.0015 × exp((현재 나이 − 40) / 8) / 체질)
주간 위험 = 1 − (1 − 연간 위험)^(1/52)
체질 = 새 생마다 0.8~1.2 사이에서 결정, 저장 이후 유지
```

사건이 수년 걸려도 주 단위로 판정하므로 긴 사건으로 노화를 건너뛸 수 없습니다. 도중에 수명이 끝나면 사건을 마치지 않은 것으로 보고 보상을 지급하지 않습니다. 난수 상태도 저장하므로 앱 재실행으로 결과를 다시 뽑을 수 없습니다.

3,000개 시드의 노화만 고려한 시뮬레이션에서 사망 나이는 중앙값 **72세**, 10~90백분위 **57~81세**였습니다. 전투·상처 사망은 별도입니다. 이 값들은 초기 밸런스이며 조정할 수 있습니다.

## 화면과 삽화

모험 / 일행·진형 / 소지품·배운 기술 / 연대기의 네 화면, 전투 화면, 결과·생애 종료 화면, 글자 크기 설정, 안내서, 이전 생 기록, 삽화 갤러리가 있습니다. 모바일 전투에서는 상태 헤더를 숨기고 행동·대상 선택을 위한 스크롤을 보조합니다.

요청에 맞춰 **삽화는 다섯 장만** 제작하고 여러 사건에서 재사용합니다. 전투 인물은 추가 삽화 대신 UI 기호로 구분합니다.

1. `web/art/village.png` — 출발 마을
2. `web/art/forest.png` — 숲길
3. `web/art/ruins.png` — 오래된 유적
4. `web/art/camp.png` — 야영지
5. `web/art/battle.png` — 전투 배경

새로 생성한 시안이며 참고 게임의 이미지를 복사하지 않았습니다. 한글 글꼴은 Noto Serif KR의 부분집합 WOFF2이며 라이선스는 `web/fonts/OFL-NotoSerifKR.txt`에 있습니다.

## 저장

각 선택과 전투 행동 뒤에 기기의 WebView 저장소에 기록합니다. 현재 사건, 전투 순서, 체력, 동료, 인벤토리, 난수 상태를 복원합니다. 이전 유효 저장을 백업 슬롯에 보관하고 기본 저장이 손상됐을 때 복구합니다. 저장 실패 시 화면에 경고합니다.

앱 삭제 또는 앱 데이터 초기화 시 저장도 삭제됩니다. 클라우드 저장은 없습니다. 동일 서명·패키지의 APK 업데이트는 앱 데이터를 유지합니다.

## 개발과 검증

Node.js 20 이상, Python 3, Chromium이 필요합니다. 게임 실행 코드에는 외부 JavaScript 라이브러리 의존성이 없습니다.

```bash
npm ci
npm test
npm run dev
# 다른 터미널에서 실행 (기본 Chromium 경로: /usr/bin/chromium)
npm run test:ui
```

`http://localhost:4173`에서 같은 게임을 미리 볼 수 있습니다. 브라우저와 APK의 저장소는 분리됩니다.

- `web/content.mjs`: 무기, 기술, 적, 동료와 사건 데이터
- `web/engine.mjs`: 재현 가능한 난수, 수명, 사건 조건, 성장, 전투, 저장 유효성
- `web/app.mjs`, `web/styles.css`: 한국어 화면과 터치 조작
- `android/`: 오프라인 WebView를 포함하는 네이티브 Android 컨테이너
- `tests/engine.test.mjs`: 규칙과 경계 상황 검사
- `tests/ui.mjs`: 실제 브라우저에서 시작부터 전투, 장비, 진형, 저장 복원, 생애 종료까지 검사

## APK 빌드

JDK 17 이상(이 환경에서는 21), Android SDK 플랫폼 35와 Build Tools 35.0.0이 필요합니다. Gradle 8.13 Wrapper를 포함했습니다.

```bash
export JAVA_HOME=/path/to/jdk
export ANDROID_HOME=/path/to/android-sdk
bash scripts/build-apk.sh
```

컨테이너가 앱 자산을 로컬 HTTPS 원점으로 제공하므로 파일 URL 권한이나 네트워크 접근이 필요 없습니다. 외부 URL 이동과 파일 접근을 막았습니다. Android 15의 시스템 바 영역 및 Android 13 이상의 뒤로 가기를 처리합니다.

현재 환경의 실제 빌드 경로는 `/workspace/toolchains/jdk`, `/workspace/toolchains/android-sdk`입니다. 샌드박스 캐시는 쓰기 가능한 위치로 설정했습니다. 개인 경로와 서명 키는 저장소에 포함하지 않습니다.

## 이번 버전의 범위

핵심 루프를 처음부터 끝까지 플레이할 수 있는 첫 버전입니다. 장기 콘텐츠 확장, 장비 등급별 대량 생성, 동료 전용 삽화, 효과음·음악, 스토어 배포, 영구 성장 시스템은 포함하지 않았습니다. 브라우저 조작·APK 빌드·서명 검증을 수행하며 실제 안드로이드 휴대폰에서의 실행 검증은 아직 하지 않았습니다.
