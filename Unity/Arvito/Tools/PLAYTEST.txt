아르비토 · ARVITO — PC 플레이테스트

Arvito.exe를 실행하세요. UnityPlayer.dll과 Arvito_Data 폴더를 함께 보관해야 합니다.

마우스 또는 1~9로 사건 선택지를 고른 뒤, ‘이 길을 선택한다’ 또는 Enter로 확정합니다.
고르기만 해서는 시간이 흐르지 않습니다. 전투는 기술/대상 선택 뒤 Enter로 행동합니다.
전투에서는 기술 → 대상 → 행동 확정 순서로 진행합니다.
Enter: 다음 사건/행동 확정, E: 여정, C: 일행, I: 소지품, J: 연대기.
Esc: 설정, F11: 전체 화면/창 모드.

모험은 열여섯에 시작합니다. 선택마다 최소 한 주가 흐릅니다.
무기는 전투가 아닐 때 소지품에서 바꿀 수 있습니다.
무기마다 사용할 수 있는 위치가 다릅니다. 자리 교대 기술로 진형을 조정하세요.
동료와 주인공의 체력에 주의하세요. 동료 사망은 해당 생에 영구적입니다.
식량을 써서 야영하거나, 전투 중 회복약과 방어/숨 고르기를 이용하세요.

행동마다 자동 저장합니다. 종료 후 이어서 읽기로 돌아올 수 있습니다.
Windows 저장: %USERPROFILE%\AppData\LocalLow\Arvito\아르비토
게임 제거 시 저장은 유지합니다.

피드백에는 어떤 사건/전투에서 어떤 선택을 했는지 알려 주세요.
오류가 생기면 저장 폴더의 Player.log와 arvito-save.json이 재현에 도움이 됩니다.
전달할 저장에는 직접 입력한 모험가 이름이 포함됩니다.

양피지 UI 0.3.2 확인 사항
- 1920x1080 / 1280x720 / 작은 창에서 사건 본문과 모든 선택지까지 스크롤 가능.
- 큰 글자 설정 후 긴 사건 제목, 선택 문장, 조건 설명이 잘리지 않음.
- 잠긴 선택지는 고를 수 없고, 선택 전 Enter는 시간/자원을 소비하지 않음.
- 선택 후 확정 1회에만 결과가 반영됨. 창 크기 변경 후에도 선택/확정 정상.
- 설정/이동/야영 창을 열었을 때 뒤쪽 사건이 키 입력에 반응하지 않음.
- 이벤트 삽화, 제목 배경, 전투 적과 동행 초상화 표시 확인.
- 작은 종이 손상은 바깥 테두리에만 표시되며 버튼 클릭을 막지 않음.
- 제목·사건 본문·결과·연대기·결말은 이순신체 Regular, 버튼·작은 수치·입력창은 Noto Serif KR.
- 업데이트 후 자동 글꼴 준비가 끝나면 F5. 설정 > 그림·글꼴 자료 확인에서 이순신체 정상 표시 확인.
- 제목 줄바꿈, 긴 사건 본문과 연대기 스크롤, 기본/큰 글자 크기에서 잘림이 없는지 확인.
- 새 인물 이름에 '뷁힣'처럼 본문에 없는 글자를 입력하고 결말·이름 표시에서 폴백 확인.
- 준비가 안 되면 재생을 멈추고 Arvito > Prepare Project 실행.
- 이순신체는 아산시 배포 글꼴. 빌드의 Licenses 폴더에 LICENSE-YiSunShin.txt와 OFL-NotoSerifKR.txt 포함 확인.

자연스러운 종이 재질 확인
- 삼각형 흠집 대신 얕고 불규칙한 가장자리, 옅은 바램, 미세한 종이 결 확인.
- 페이지 이동/창 크기 변경 때 질감이 깜빡이지 않는지 확인.
- 버튼 클릭·선택 확정·본문 스크롤이 종이 장식에 가로막히지 않는지 확인.
- 종이 결은 글·삽화 아래에만 표시. 삽화의 도트와 이순신체는 유지.
- UI/paper-grain.png는 Bilinear/Repeat, 이벤트 삽화는 기존 Point 설정 유지.
