# 이벤트 삽화 제작 자료

`scenes.json`은 카탈로그의 500개 이벤트 ID, 원문, 장면별 구성 지시와 이미지 이름을 연결합니다. `prompts/`는 생성에 사용할 4×4 장면 시트의 지시문입니다. `sources.json`에는 실제로 사용한 생성 원본의 이름, SHA-256과 잘라낸 이벤트 목록이 남습니다. 생성 원본은 별도로 보존하며 게임에는 각 장면의 작은 PNG만 포함합니다.

그림은 아르비토를 위해 새로 생성한 삽화입니다. 기존 작품의 이미지를 사용하거나 사람이 직접 그렸다고 표시하지 않습니다.

## 표현 기준

- 192×128 실제 픽셀, 그림당 최대 32색, 불투명 PNG. 디더링과 색상 보간을 쓰지 않습니다.
- 차분한 흙색·회청색·올리브색을 바탕으로 한 판타지 카툰. 과장된 각진 얼굴이나 굵은 윤곽선 대신 기존 그림의 자연스러운 선을 유지합니다.
- 인물을 모두 짧고 둥근 체형으로 만들지 않습니다. 사냥꾼은 날렵하게, 노인은 마르고 굽게, 전사는 넓은 어깨와 구분되는 허리로 표현합니다. 체형과 자세에 차이를 두되 과장된 도형처럼 만들지 않습니다.
- 인간의 눈은 점·흰자·눈꺼풀 선으로 따로 그리지 않습니다. 원래 피부색과 명암을 유지하며 코·입·고개·자세로 표정을 전달합니다. 눈 자리에 검은 가로 띠나 안대를 만들지 않습니다.
- 주인공과 임의의 동료는 몸, 손, 뒷모습, 그림자, 무기 등으로도 고정하지 않습니다. 사건에 명시된 NPC, 적, 동물과 장소만 등장합니다.
- 같은 사건의 갈림길, 조사, 협상, 두 후일담은 서로 다른 장면으로 구성합니다. 결과가 정해지기 전 그림에 특정 선택의 해결 결과를 넣지 않습니다.

## 편집과 검증

1. 카탈로그나 사건을 변경한 뒤 `python3 scripts/prepare-event-art.py`로 구성 자료를 갱신합니다.
2. 지시문과 스타일 참고 이미지를 이용해 1536×1024, 4×4 배열의 장면 시트를 생성합니다. 생성 결과를 직접 검토합니다.
3. `node scripts/import-event-art.mjs <시트 번호> <원본 PNG>`로 잘라내고 Point 방식으로 192×128에 맞춥니다. 최대 32색의 indexed PNG로 저장하며 색상 보간은 하지 않습니다. 이 단계는 그림의 내용을 새로 그리는 작업이 아니라 픽셀 규격과 팔레트 변환입니다. 원본 파일은 보존합니다.
4. `python3 scripts/write-unity-metadata.py`로 새 파일의 고정 GUID를 준비합니다.
5. `python3 scripts/check-event-art.py`로 500개 일대일 연결, 중복 이미지, 크기·색수·알파와 Unity 메타데이터를 검사합니다. 모든 시트의 검토 SHA-256이 실제 원본과 일치하고 보정 목록도 완료됐는지 확인합니다. Pillow가 필요합니다. 작업 중에는 `--partial`을 사용할 수 있습니다.
6. `python3 scripts/build-event-art-gallery.py`로 원본 PNG와 검색 가능한 오프라인 삽화집을 만듭니다. 기본 출력은 `/workspace/artifacts/Arvito-Event-Art`이며 `--output`으로 바꿀 수 있습니다.

`review.json`은 실제 눈으로 확인한 시트와 수정 필요 여부를 기록합니다. 보정이 필요하면 `repairs.json`에 이벤트 ID와 이유·새 구도를 추가하고, 1번 명령으로 `repair-prompts/`를 갱신합니다. 보정 시트는 `node scripts/import-event-art.mjs <보정 시트 번호> <원본 PNG> --repair`로 해당 장면만 교체합니다. 다시 직접 검토한 뒤 보정 시트를 `reviewed`, 원래 시트를 `reviewed-with-repairs`로 기록합니다. 검증 스크립트는 그림의 의미를 자동 판정하지 않으므로 이러한 시각 검토를 생략하지 않습니다.

게임 이미지는 `Unity/Arvito/Assets/Resources/Arvito/Art/Events/<eventId>.png`입니다. `EventArt`가 현재 이벤트의 그림을 필요할 때 로드합니다. `EventArtImporter`는 Point 필터·무압축·밉맵 없음·NPOT 크기 유지를 적용합니다. 여정과 결과 화면은 기존 `PixelArtImage`를 이용해 전체 3:2 그림을 같은 정수 배율로 표시합니다. 기존 지역/전투 배경은 해당 용도로 유지하며, 이벤트 그림이 없는 경우에만 대체 표시합니다.
