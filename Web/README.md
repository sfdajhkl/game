# 아르비토 — 브라우저 RPG

Unity 없이 실행되는 HTML/CSS/JavaScript 게임. `web/`이 실제 게임 소스이며 `node build.mjs`로 `dist/`를 만듭니다. `npm ci && npm test`로 핵심 게임 규칙과 저장을 검사합니다.

100개 사건, 10개 지역, 단계별 가중치, 수명·성장·장비·진형·주인공 조작/동료 자동 전투를 포함합니다. 삽화/폰트/종이 결은 기존 Unity 프로젝트와 같은 자료를 사용합니다. 파일은 `web/art/Events/<event-id>.png`로 개별 로드합니다.

저장: 현재 브라우저의 localStorage에 자동 저장. 설정에서 JSON 내보내기/가져오기 가능. 이전 Unity 저장의 배열형 flags/counters를 읽을 수 있지만 기기 간 자동 동기화하지 않습니다. 웹 저장은 별도 키 `arvito.browser.v1`을 사용합니다.

`web/events.mjs`는 웹에서 새로 쓴 100개 완결형 사건입니다. `web/catalog.mjs`에는 장비·적·지역을 보관합니다. Unity JSON으로 덮어쓰지 마세요. 새 사이트의 .openai/hosting.json은 기존 Site ID를 유지해야 합니다.

정식 플레이는 배포 URL에서 가능합니다. 현재 Sites 접근 범위는 소유자 전용입니다. 별도 공개 요청 없이 공개 범위를 넓히지 않습니다.

## 배포와 수정

실행 주소: https://arvito-travelers-book.choibumsoo.chatgpt.site

GitHub의 `Web/`을 웹 버전 수정 원본으로 관리합니다. Sites 소스 저장소에는 이 디렉터리 내용을 루트로 동기화합니다. `web/` 수정 후 테스트·빌드하고, 정확히 같은 소스를 Sites 저장소에 Push한 뒤 `.openai/hosting.json`과 `dist/`를 패키징하여 배포합니다. GitHub Push 자체는 자동 배포를 실행하지 않습니다. 비밀 토큰은 저장소에 넣지 않습니다.

Unity로 이식할 때 삽화와 사건 데이터는 재사용할 수 있지만 화면 및 JavaScript 게임 로직은 C# 쪽에 별도로 반영해야 합니다.

## 능력치와 글꼴

1.1.1부터 UI·수치·버튼·상태·설정은 Noto Sans KR, 사건 제목과 이야기 본문은 이순신체를 사용합니다. UI 폰트는 SIL OFL 1.1으로 배포되며 현대 한글 11,172음절을 모두 포함하여 글자별 대체 글꼴이 생기던 문제를 방지합니다. 장식용 메모·하단 격언·감성 부제·홍보 문구를 제거했습니다. 앞으로의 UI 작업은 `AGENTS.md`의 문구·글꼴 원칙을 따릅니다. 1.2부터 승인된 3번 시안의 오른쪽 상태표로 바꾸며, 작은 화면에서는 위쪽 3열 × 2행으로 접습니다. 글자·수치·서로 다른 아이콘과 절제된 색을 함께 표시하고 클릭하면 설명을 엽니다.

- 힘: 근접 피해, 힘을 쓰는 사건 판정.
- 민첩: 활·단검 피해, 민첩 판정.
- 지능: 마법 피해, 지식·해독·장치 조사.
- 지혜: 관찰·통찰, 긴장 저항(4마다 받는 긴장 -1).
- 매력: 설득·협상·증언 수집.
- 건강: 위험한 환경 판정, 증가 1당 최대 체력 +2 및 야영 주인공 추가 회복 +1.

초기값은 모두 4입니다. 6종 모두 사건 판정과 성장 보상을 갖습니다. 1.0 저장(version 1)은 자동 변환합니다: 힘/민첩 유지, wit→지능, will→지혜, 매력/건강은 4로 시작합니다. 이전 체력·최대 체력·진행·난수는 그대로 유지하며 전투 보상에 남은 옛 키도 변환합니다. 새 저장 version은 2이고 Unity로 역변환하지 않습니다.

## UI와 제목 서체

게임 제목은 **ARVITO**이며, 제목/로고에만 SIL OFL 1.1의 UnifrakturCook 서체를 사용합니다. 나머지 UI는 Noto Sans KR, 사건 제목과 이야기 본문은 이순신체를 유지합니다. 제목 서체 원본은 https://github.com/google/fonts/tree/main/ofl/unifrakturcook 이며 WOFF 변환본과 라이선스를 `web/fonts/`에 포함합니다.

가로 메뉴, 왼쪽 삽화와 본문, 오른쪽의 작은 체력·긴장·능력치 표로 구성합니다. 주인공 체력은 상단 자원 줄에서 중복 표시하지 않습니다. 자연스러운 밝은 종이 배경 `natural-parchment.png`를 새로 생성했고, 반복 타일/진한 가장자리 음영을 줄였습니다.

`viewport.css`는 100dvh 높이에 화면을 맞추고 기존 최소 880px 높이를 없앱니다. `viewport.mjs`는 남은 영역을 실제 DOM 치수로 측정하여 넘치는 기록·선택지 등을 이전/다음 페이지로 나눕니다. 긴 문단은 글자를 보존하며 분할하고, 버튼은 쪼개지 않습니다. 페이지 이동 자체는 시간·자원·저장 상태를 바꾸지 않습니다. 설정/기록 가져오기 등 팝업은 아주 작은 창에서 내부 스크롤을 허용합니다.

`tests/viewport.test.mjs`는 명시적인 가상 치수를 사용한 DOM 검사입니다. 긴 문단의 문자 보존, 모든 선택지/확정 버튼 보존, 짧은 화면의 페이지 버튼 생략, 100개 사건 템플릿의 본문/선택지/6종 상태표를 검사합니다. 브라우저 렌더링 검증을 대신하지 않습니다. 이번 환경의 Browser Use 연결 오류로 실제 화면 크기별 시각 검증은 완료하지 못했습니다.

## 1.3: 사건 재작성 및 삽화 확대

500개의 분할 장면을 100개의 완결된 사건(선택지 207개)으로 재작성했습니다. 각 사건은 상황·행동·성공/실패의 인과를 자체적으로 설명합니다. 추첨은 지역·진행 단계·조건을 따르고, 재회/유적/용의 선행 조건은 유지합니다. 단순한 쉬기/보급/수련은 반복 가능하여 일회성 사건을 소진해도 플레이가 막히지 않습니다.

`legacy-events.mjs`는 삭제한 400개 사건 ID의 고정 매핑입니다. 이전 저장을 불러와도 난수·나이·재화·체력·연대기를 바꾸거나 진행 중 전투/결과 보상을 다시 지급하지 않습니다. 진행 중인 오래된 결과 문장은 그 장면을 마칠 때까지 보존됩니다.

삽화의 열 폭을 넓히고 높이 256px·페이지 폭 300px 제한을 없앴습니다. 선택지 공간을 남긴 뒤 정수 물리 픽셀 배율로 확대합니다. ARVITO 로고에는 끝획이 날카로운 UnifrakturCook Bold를 적용합니다.

## 1.3.1: 삽화를 이벤트 영역 높이까지 확대

큰 화면은 이벤트 영역 왼쪽 약 64%를 삽화로 채우고 오른쪽 36%(최소 320px)에 본문·선택지를 배치합니다. 이미지의 가로세로 비율과 정수 물리 픽셀 배율을 유지하면서 프레임 밖 가장자리를 잘라 빈 띠를 없앱니다. 텍스트가 길면 읽기 열만 페이지로 나누며 삽화는 계속 표시합니다. 폭 900px 이하에서는 위쪽 46%를 삽화, 아래쪽을 페이지로 구성합니다. 6종 능력치와 메뉴는 기존대로 표시합니다.
