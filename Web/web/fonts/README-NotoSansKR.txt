UI font: Noto Sans KR (variable weight 100–900)
Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
Original: NotoSansKR[wght].ttf
License: SIL Open Font License 1.1; see OFL-NotoSansKR.txt.

NotoSansKR-UI.woff is a WOFF conversion/subset of the official font.
It preserves all 11,172 modern Hangul syllables, Hangul Jamo,
compatibility Jamo, Latin, punctuation, arrows and full-width forms.
The subset is not limited to the currently displayed game text.
No glyph outlines were redesigned. The reserved name 'Source' is not used.
